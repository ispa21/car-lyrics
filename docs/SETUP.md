# Setting up Lyrics Dash

A step-by-step guide to getting Lyrics Dash onto an iPhone and into the car, written so anyone can do it from scratch.

Lyrics Dash shows synced lyrics on CarPlay as a Live Activity. It works with Spotify and Apple Music, and lyrics come from LRCLIB.

**Where things are**
- Xcode project: generated by `xcodegen` as `LyricsDash.xcodeproj` in the repo root
- Spotify developer app: [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard)
- Developer notes, design decisions and tests: `README.md` and `FEASIBILITY.md`

## What you need
| Need | Why |
| --- | --- |
| An iPhone 11 or newer on **iOS 26 or later** | CarPlay only shows Live Activities from iOS 26. On iOS 18 the app can't reach the car screen at all. |
| A Mac with Xcode 27 | It builds the app and puts it on the phone. |
| Your Apple ID signed into Xcode | Signs the app. Find your team ID in Xcode → Settings → Accounts. |
| A cable that carries data | For the first install on each phone. |
| Spotify Premium | Spotify only lets Premium accounts use a developer app like this one. Apple Music needs nothing extra. |
| Internet on the phone (mobile data or the car's hotspot) | Lyrics Dash asks Spotify what's playing and fetches lyrics. |

## 1. Prepare the Mac (once)
1. Install **Xcode** from the App Store, open it once, and accept the "install additional components" prompt.
2. Install XcodeGen, which generates the Xcode project, by running this in Terminal:
   ```sh
   brew install xcodegen
   ```
3. In Xcode, open **Settings → Accounts** and sign in with your Apple ID.

## 1b. Your local config (once)
```sh
cp Local.xcconfig.example Local.xcconfig
```
Fill in `DEVELOPMENT_TEAM` (your Apple team ID) and, for Spotify, `SPOTIFY_CLIENT_ID`. `Local.xcconfig` is gitignored, so these never get committed. Then run `xcodegen`. If Xcode says the bundle ID is taken, change `bundleIdPrefix` and every `com.ishanpatil` in `project.yml` to your own reverse-domain name.

## 2. Prepare an iPhone (once per phone)
1. **Check the model and iOS version:** Settings → General → About. It needs an iPhone 11 or newer.
2. **Update to iOS 26 if needed:** Settings → General → Software Update. An iPhone XS or XR can't run iOS 26, so it can't show lyrics in CarPlay.
3. **Connect it to your Mac** with the cable, unlock it, and tap **Trust**.
4. **Turn on Developer Mode:** Settings → Privacy & Security → Developer Mode, then let it restart. The option only appears after the phone has been connected to Xcode once.

The Apple ID the phone is signed into doesn't matter. Apps from Xcode are signed with your account on your Mac.

## 3. Install or update the app
Do this for the first install, after any code change, and every 7 days.
1. Open `LyricsDash.xcodeproj`. In Terminal:
   ```sh
   open LyricsDash.xcodeproj
   ```
2. Plug in the phone and unlock it.
3. In the toolbar at the top of Xcode, click the device name next to **LyricsDash** and choose the phone.
4. Press **⌘R**. The first build takes a few minutes.
5. **First install only:** if the phone says "Untrusted Developer", go to Settings → General → VPN & Device Management, tap your Apple ID, then tap **Trust**.
6. **Press ■ Stop in Xcode, then open Lyrics Dash by tapping its icon.** While Xcode is attached, iOS treats the app differently in the background, so always do real tests and drives from the icon.

**The 7-day limit:** with a free Apple ID, the app stops opening 7 days after you install it. Plug in and press ⌘R again to renew it; your settings are kept. A paid Apple Developer Program membership ($99 a year) makes each install last a year.

**Renewing without a cable:** after the first wired install, open **Window → Devices and Simulators** in Xcode, select the phone and tick **Connect via network**. While the phone and Mac are on the same Wi-Fi, you can pick it and press ⌘R without plugging in.

**If you add, rename or delete code files, or edit `project.yml`:** regenerate the project first, then reopen it in Xcode.
```sh
xcodegen
```

## 4. Spotify (once)
Skip this for Apple Music only. Otherwise:
1. On [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard), choose **Create app**.
   - **Redirect URI:** `lyricsdash://callback`
   - **APIs used:** Web API
2. Copy the app's **Client ID** into `SPOTIFY_CLIENT_ID` in `Local.xcconfig` (see step 1b), run `xcodegen`, then reinstall the app (step 3).
3. **Using a different Spotify account on another phone?** Add that account's email under **User Management** in the dashboard. Up to 5 accounts are allowed.

## 5. Use it in the car
1. **Connect the phone to CarPlay.** If two phones are in the car, make sure the car connects to the one with Lyrics Dash, since CarPlay uses one phone at a time.
2. **Open Lyrics Dash**, pick **Spotify** or **Apple Music** under Listen with, and tap the button at the bottom. The first time it reads **Connect Spotify** (or **Allow Apple Music**); after that it reads **Start lyrics**.
3. **Tap Start lyrics** while the phone is unlocked. iOS only lets a Live Activity start from the open app. If something is in the way (Live Activities off, access not allowed), Home says so and the bottom button becomes the fix.
4. **First time only:** allow **Location** ("Allow While Using App") when asked.
5. **Play music.** The lyrics card appears on the CarPlay Home Screen and the phone's Lock Screen. You can now switch apps or lock the phone.
6. **Tap Stop lyrics when you're done.** It also stops by itself once nothing has played for 20 minutes. Change that time in Settings → **Keep running**.

While it runs, Home shows the card as it is on the Lock Screen and CarPlay, the song and whether it has synced lyrics, a timing control, and a **Status** row. Status shows, in plain words, whether the lyrics, the Lock Screen card, the Dynamic Island, CarPlay, the widgets and Keep running are all working.

## 6. Settings in the app
Tap the gear on Home for Settings. Tap the card on Home (or **Edit card**) for Appearance.

| Setting | What it does |
| --- | --- |
| **Timing** | If lines appear after they're sung, tap + (0.1 s at a time) until they change as they're sung. It's also on Home while lyrics run, so you can watch the card as you adjust it. Tune it in the car, because the CarPlay Simulator adds its own delay. |
| **Keep running** | How the app keeps running when you leave it: **Silent audio**, **Location**, or both (recommended). Turn Silent audio off if your car lowers the radio while Lyrics Dash runs. |
| **Appearance** | Presets, then Layout (Minimal, Big, Detailed, Karaoke), Text (font, weight, size, spacing) and Colour, under a live preview. **Make your own** saves the current look under a name (touch and hold it to rename, update or delete). **Surprise me** and the dice button pick random looks that stay easy to read; **Previous look** goes back. **See it live** runs the demo song so you can check the real card on the Lock Screen and CarPlay. |
| **Widgets** | **Real-time lines** for the Home Screen widget, and timing for the **Home Screen widget** and the **CarPlay widget**. |
| **Offline lyrics → Check a song** | Search a song and tap it to see whether LRCLIB has synced lyrics for it. |

Settings are stored on each phone, so set them again on a new phone.

## 6a. Lyrics without signal (optional)
Settings → **Offline lyrics**:
- **Road trip mode:** turn it on before a drive. While lyrics run, it saves lyrics for the next 20 songs in your Spotify queue.
- **Save ahead:** on Wi-Fi, tap **Apple Music library**, **Spotify Liked Songs**, or **Spotify playlists** to save lyrics in bulk. Keep the app open until it finishes. The first time, tap **Allow Liked Songs and playlists** and log in to Spotify again.
- Every song you play is saved automatically too. Saved lyrics take a few MB at most.

## 6b. Add the lyrics widget (optional)
- **Home Screen or StandBy:** touch and hold the Home Screen, tap **Edit → Add Widget**, search **Lyrics Dash**, and pick a size.
- **Lock Screen:** touch and hold the Lock Screen, tap **Customize → Lock Screen**, then add **Lyrics Dash** under the clock.
- **CarPlay:** Settings → General → CarPlay → your car → **Widgets**, and add Lyrics Dash. It appears on the CarPlay widgets page.

When Lyrics Dash isn't running, the widget is a **Start lyrics** button: tap it to open the app and start following the source picked on Home (Spotify or Apple Music). Widget lyrics are a little looser than the CarPlay card, since iOS redraws widgets about every 2 seconds at most.

## 7. Test without a car
**CarPlay Simulator (shows the real card from your phone):**
1. Download **Additional Tools for Xcode 27** from [developer.apple.com/download/all](https://developer.apple.com/download/all/).
2. Open the disk image and drag **Hardware → CarPlay Simulator** into Applications.
3. Plug in the phone, unlock it, open CarPlay Simulator, and tap **Allow** on the phone.

**Demo song:** **Try the demo song** (under the button on Home) plays a built-in 60-second test song without Spotify. It's useful for checking the card and its timing.

## Adding a second iPhone (for example one that lives in the car)
1. **Check it can run iOS 26** (Settings → General → About: iPhone 11 or newer) and update it (Settings → General → Software Update).
2. **Connect it to your Mac** and do section 2 (Trust, Developer Mode).
3. **Install the app** with section 3, choosing the car phone in Xcode's toolbar.
4. **On the car phone:** install Spotify and sign in, then open Lyrics Dash, tap **Connect Spotify**, and set up Timing, Keep running and Appearance again.
5. **Renew every 7 days:** bring the phone to the Mac and press ⌘R, or renew over Wi-Fi if the car is parked within range of your Wi-Fi network. If renewing gets tiresome, the $99 membership makes each install last a year.

A free Apple ID can have at most 3 apps from Xcode on each phone at once.

## When something goes wrong
| What you see | What to do |
| --- | --- |
| Xcode says the phone's iOS is too old | Update the phone to iOS 26 (section 2). |
| The phone isn't in Xcode's device list | Unlock it, check the cable, tap Trust, and turn on Developer Mode. |
| "Untrusted Developer" on the phone | Settings → General → VPN & Device Management → your Apple ID → Trust. |
| Xcode: maximum number of apps for free development | Delete one of the other apps installed from Xcode on that phone, then ⌘R again. |
| The app won't open after about a week | The 7-day limit. Plug in and press ⌘R. |
| No card on CarPlay | The phone must be on iOS 26, Live Activities must be on (Settings → Lyrics Dash → Live Activities), and you must tap Start with the phone unlocked. Also check that Live Activities are allowed for your car in Settings → General → CarPlay. |
| The card says "Lyrics paused · open Lyrics Dash" | iOS stopped the app. Open it: Home explains what happened, and lyrics carry on. Check that Settings → Keep running has at least one option on. |
| Lyrics stop moving when you leave the app | Turn on both options in Settings → Keep running, and start the app from its icon, not Xcode. Settings → Troubleshooting → Event log shows "App was paused" lines if iOS paused it. |
| Lyrics are late or early | Timing, on Home while lyrics run or in Settings. |
| "Spotify refused access" | The Spotify account needs Premium and must be listed under User Management in the dashboard. |
| "No synced lyrics on LRCLIB" | LRCLIB doesn't have timed lyrics for that song. Check it in Settings → Offline lyrics → Check a song. |
| "LRCLIB is busy right now" | LRCLIB is overloaded. The app retries by itself; try again a minute later. |
| Anything else odd with the card | Look at **Status** on Home first. Then Settings → **Troubleshooting** → **Share latest session log**, or open an older session (newest first, named by day and time) → **Share**. Each session is a detailed log from Start to Stop. |
